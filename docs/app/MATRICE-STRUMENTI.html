  • Windows ARM64: PHP, Apache, Nginx, MySQL, MongoDB, Android SDK, Julia, TinyTeX e l'editor usano la build x64 in emulazione; R non ha build. Rust usa l'host aarch64-pc-windows-gnullvm con llvm-mingw di C/C++ come linker.
  • Apache: su Windows Apache Lounge con il modulo PHP; su macOS e Linux la build del kit con php-fpm (D-116), offerta lì quando il primo rilascio httpd-v2.4.69-1 è fissato nel catalogo. Si propone solo per i progetti con regole proprie nel .htaccess; Caddy è il server web predefinito su tutti i sistemi.
  • Nginx: solo Windows (D-111), da togliere dopo la migrazione dei pool a Caddy (issue #4).
  • MySQL è l'unico server SQL del kit (D-117): MariaDB non si offre più, i suoi dati passano a MySQL al primo avvio; phpMyAdmin apre MySQL su tutti i sistemi.
  • Android SDK: Google non pubblica platform-tools e build-tools per Linux ARM64.
  • C/C++ su macOS e Linux: shim su zig cc del kit (richiede Zig); i framework Apple vogliono Xcode CLT.
  • Fonte dei dati: components.json (campi targets, unavailable, noArm64, x64Only, rosetta, needs, needsByTarget) con la logica di Component::is_available_on in tauri/src/setup/catalog.rs; dimensioni e fonti da docs/app/CATALOG.md.
